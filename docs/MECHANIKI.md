# Пилот «Механики»

Первый рабочий пример сайта на Vox CMS. Контент и контакты взяты из mechaniki.ru и сопровождаемого репозитория ultima-vox/mechaniki.ru; тексты интерфейса переработаны для нового оформления. Фотография мастерской и логотип — с действующего сайта/репозитория; Manrope поставляется локально с OFL.

После онлайн-обновления:

1. «Модули» → «Синхронизировать» → включить «Механики — пилотный сайт».
2. В меню появится «Механики · MVP». Нажмите «Создать страницы „Механиков“».
3. Откройте `/mechaniki` на тестовом домене.

Создаются шесть опубликованных страниц внутри `/mechaniki`. Главная существующего сайта и другие материалы сохраняются. Повторный импорт при наличии этого раздела отклоняется целиком; импорт выполняется транзакционно для выбранного в админке сайта. Новые таблицы и миграции не нужны.

Тексты разделов находятся в обычных Documents (код `node-<id>`), адреса, названия и H1 — в Structure. Общие шапка, первый экран, подвал и оформление — в макете `mechaniki`. Для переопределения шаблона используйте «Макеты»: сохранённая версия будет в `storage/templates`, где онлайн-обновление её не заменяет.

Это пилот нового интерфейса на новой CMS, не перенос действующего HostCMS. Онлайн-заявки, отзывы, полный каталог и SEO-перенос пока не подключены; запись доступна через явную телефонную ссылку. Страницы отмечены `noindex, nofollow`; рабочий mechaniki.ru не меняется. Раздел не назначается главной автоматически — сначала нужно оценить новый интерфейс и модель редактирования.
