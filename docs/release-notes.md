# Изменения выпуска

- По обратной связи навигация админки собрана в единое левое меню: разделы раскрываются вертикально, пункты находятся внутри разделов. Текущий раздел открыт автоматически; горизонтальные вкладки и второе меню убраны. Сайт, поиск Ctrl+K и учётная запись остаются в верхней панели.

- В списке инфосистем добавлены поиск по названию/коду, активность, сортировка и страницы по 25/50/100 записей. Фильтры и папка сохраняются при переходе между страницами; выборка ограничивается текущим сайтом в SQL.

- Установщик проверяет доступность адреса и закрытие приватных путей до создания таблиц, администратора и конфигурации.
- Утечка private, перенаправление или недоступная проверка останавливают установку; временный контрольный файл удаляется.
- Проверка использует фиксированные пути, закреплённый DNS-адрес и проверку TLS; внутренние адреса запрещены без точного разрешения владельца PHP-процесса.
- Добавлены реальные Apache-сценарии отказа без изменения БД и проверки подменённых внутренних URL.
