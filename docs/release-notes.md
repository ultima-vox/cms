# Изменения выпуска

- Список инфосистем: поиск по названию и коду, фильтр активности, сортировка, страницы по 25/50/100 записей.
- Выборка и счётчики ограничены текущим сайтом и папкой в SQL; поиск и фильтры сохраняются при переходе между страницами.
- Добавлены проверки PostgreSQL, MySQL и MariaDB и браузерный сценарий на 1440, 1024 и 390 px.
- Изменения принадлежат модулю ИС: без новых файлов Core/config и миграций БД.
