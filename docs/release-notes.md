# Обновления CMS

- Модуль обновлений подключён через штатные права, меню и маршруты CMS; отдельный ZIP устанавливается менеджером модулей.
- Добавлены проверка готовности сервера, сохранение списка изменений на 24 часа и история операций с резервными копиями.
- Добавлены транзакционные миграции ядра и включённых модулей, автоматическая синхронизация модулей и прав после установки.
- Восстановление прерванного обновления учитывает фактический результат транзакции PostgreSQL; все запросы защищены во время замены кода.
