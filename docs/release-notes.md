# Изменения выпуска

- Documents: история показывает автора новых версий. При сохранении устаревшей формы CMS отклоняет перезапись и сохраняет введённый текст; актуальную версию можно открыть отдельно. Формы, открытые до обновления, нужно открыть заново. Авторы старых версий остаются неизвестными.

- Макеты: поиск по названию и коду, сортировка, страницы по 25/50/100 записей с сохранением выбранной папки. Список выбирает данные в SQL; на узких экранах подписи счётчиков и длинные пути остаются читаемыми.

- Общие стили и скрипты админки получают версию в URL: после обновления CMS браузер запрашивает актуальный обработчик форм и оформление.

- Закреплённая панель сохранения и отмены подключена также к настройкам инфосистемы, группам и элементам. Сохранение элемента использует выбранные статус и дату публикации; ошибки полей сохраняют доступ к исправлению и повторной отправке.

- В документах действия сохранения черновика, публикации и отмены доступны в закреплённой панели длинной формы. Исправлена передача выбранного действия при ожидании отправки; повторная отправка блокируется до ответа.

- По обратной связи навигация админки собрана в единое левое меню: разделы раскрываются вертикально, пункты находятся внутри разделов. Текущий раздел открыт автоматически; горизонтальные вкладки и второе меню убраны. Сайт, поиск Ctrl+K и учётная запись остаются в верхней панели.

- В списке инфосистем добавлены поиск по названию/коду, активность, сортировка и страницы по 25/50/100 записей. Фильтры и папка сохраняются при переходе между страницами; выборка ограничивается текущим сайтом в SQL.

- Установщик проверяет доступность адреса и закрытие приватных путей до создания таблиц, администратора и конфигурации.
- Утечка private, перенаправление или недоступная проверка останавливают установку; временный контрольный файл удаляется.
- Проверка использует фиксированные пути, закреплённый DNS-адрес и проверку TLS; внутренние адреса запрещены без точного разрешения владельца PHP-процесса.
- Добавлены реальные Apache-сценарии отказа без изменения БД и проверки подменённых внутренних URL.
