# Папки и мультисайтовость

- В документах, инфосистемах и макетах появились вложенные папки с переносом материалов, переименованием и удалением пустых папок.
- Макеты и их редактируемые файлы разделены по сайтам; одинаковые коды документов, ИС и макетов не пересекаются между сайтами.
- Добавлено явное назначение доступа пользователей к сайтам, изоляция новых записей аудита и защита форм при переключении сайта в другой вкладке.
- Исправлены подтверждения удаления и редактор полей ИС при включённой политике CSP; обновление установленной CMS проверяется с реальной версии 0.1.20.
