# Изменения выпуска

- PostgreSQL остаётся СУБД по умолчанию; в установщике добавлен явный выбор MySQL/MariaDB (legacy) без изменения корня сайта.
- Добавлены отдельные legacy-миграции Core и модулей, переносимые запросы публикации, папок, макетов, ИС и JSON-фильтров.
- Онлайн-обновление MySQL/MariaDB защищено приватным снимком БД, маркером завершения и восстановлением после SQL-сбоя; PostgreSQL сохраняет транзакционный механизм.
- Исправлена запись групп и редактирование элементов ИС; проверки расширены на PostgreSQL, MySQL и MariaDB.
- По официальной документации HostCMS записан общий план развития UX, контента и модулей с сохранением лёгкого нативного PHP-ядра.
