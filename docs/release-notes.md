# Изменения выпуска

- В списке документов появились поиск по названию/коду, фильтры публикации и черновиков, сортировка и страницы по 25/50/100 записей.
- Фильтры выполняются в БД выбранного сайта и папки; переход между страницами сохраняет параметры поиска.
- Создание папки свёрнуто под отдельное действие; навигация по папкам стала компактнее в документах, ИС и макетах.
- Добавлены понятные пустые результаты, адаптивные элементы списка и браузерная проверка поиска/пагинации на 1440, 1024 и 390 px.
- Проверки списка выполняются на PostgreSQL, MySQL и MariaDB без изменения схемы БД и новых доменных конструкций в Core.
