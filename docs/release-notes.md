# Изменения выпуска

- Проверка обеих раскладок дистрибутива на настоящем Apache с PHP 8.4: установка, работа редактора, маршрутизация и защита приватных файлов.
- Добавлен отрицательный стенд с отключёнными .htaccess: тест обязан обнаружить утечку, а не выдавать ложное подтверждение защиты.
- Требования владельца shared-хостинга не изменены; Docker используется только в CI.
