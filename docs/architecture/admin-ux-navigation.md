# ADR: вертикальная навигация администратора

Дата: 2026-10-20. Задача [#156](https://github.com/ultima-vox/cms/issues/156), родитель [#109](https://github.com/ultima-vox/cms/issues/109).

## Основание и актуальное решение

Владелец проверил выпуск v0.1.178 и отверг горизонтальную раскладку PR162. Его скриншоты HostCMS показывают один левый список: основные разделы раскрываются на месте, дочерние пункты находятся непосредственно под разделом. Эта обратная связь заменяет прежнее решение о верхней глобальной навигации и отдельном локальном sidebar. Метаданные PR161 сохраняются.

Использовать единую вертикальную навигацию слева. «Обзор» — одна прямая ссылка, затем зарегистрированные непустые разделы «Контент», «Оформление», «Сервисы», «Система». Каждый раздел — нативный `details/summary`, внутри — ссылки зарегистрированных владельцами пунктов. Открытие раздела не меняет URL и не покидает редактируемую форму. Текущий пункт помечен `aria-current=page`; его раздел открыт сервером при прямом переходе и reload. Нативное имя accordion группирует раскрытия без обязательного JS; браузеры без поддержки эксклюзивного открытия допускают несколько открытых групп.

Верхняя служебная строка содержит бренд, заголовок, сайт, поиск Ctrl+K и учётную запись. Горизонтальных разделов и второго локального меню нет. На широком экране левое меню остаётся доступным при прокрутке и имеет собственную прокрутку при нехватке высоты. На мобильном экране один подписанный disclosure раскрывает всё меню, внутри сохраняются те же группы. Без JS меню доступно. Один набор DOM-ссылок, без desktop/mobile копий, без ARIA menu/menubar. Escape возвращает фокус к summary группы на desktop или общей навигации на mobile.

## Контракт и границы

Core0.6 / Extension API1.2: необязательный `section` в существующих `AdminApi::navigation()` и `AdminNavigationItem`, default `services`. `AdminShellContext::navigationSections()` группирует уже разрешённые пункты и убирает пустые разделы. Владельцы сами указывают размещение. Shell не содержит списка бизнес-модулей, SQL к их таблицам или новых настроек маршрутизации.

Documents1.5, Infosystem1.6, Sites1.3, Updater1.4 требуют Core>=0.6 и API^1.0 для совместимости с old-worker update pipeline. Вертикальная корректировка меняет представление существующего контракта; не требует новой схемы, миграций, файлов Core/config или изменения domain APIs. Права endpoint, CSRF, выбранный сайт, публикация, переходы page/editor и контекст списков сохраняются. Старое предпочтение collapsed sidebar не скрывает подписи. Ctrl+K продолжает искать весь разрешённый registry, в том числе закрытые группы и старые расширения.

Не копировать отсутствующие функции HostCMS в виде неработающих пунктов. Избранное/saved views (#157), действия длинных форм (#158), revision-aware dirty guard/autosave и публичное меню (#110) остаются отдельными задачами. Не включать другую интеграцию редактора вместо PR154.

## Проверки

- Реальная ограниченная роль, два сайта, legacy fallback; разрешённые группы и ссылки, отсутствие пустых/запрещённых разделов, один текущий пункт и раскрытый раздел: `tests/admin_navigation_smoke.php` на пяти СУБД.
- 390/1024/1440: вертикальное положение sidebar, отсутствие горизонтального меню/overflow, клавиатурное раскрытие без перехода, выбор документа, direct/reload, закрытие Escape/focus, переход через Ctrl+K в закрытую группу: `tests/browser_mvp.cjs`.
- Без JS и при запрещённом localStorage; 720px effective viewport проверяет reflow эквивалентный 1440px/200%, без заявления полной WCAG-сертификации.
- Полный CI, package/install/update, существующие HTTP site/CSRF/permission guards, editor/list-return и fresh-process module removal. GitHub release не означает deployment на хостинг.

## Источники

- [Интерфейс HostCMS](https://www.hostcms.ru/hostcms/interface/): левое меню, верхняя служебная строка, навигационная цепочка.
- Скриншоты владельца от 2026-10-20: раскрытые группы «Контент» и «Система», организация общего левого меню.
- [W3C disclosure navigation](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/): обычная ссылочная навигация и disclosure вместо ARIA application menu.

Перенимается пользовательский процесс. Код, оформление фоновых изображений, XML/XSLT и архитектура HostCMS не копируются.
